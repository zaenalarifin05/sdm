# SDM Pabrik

Aplikasi Pengelolaan Sumber Daya Manusia untuk presensi, jadwal shift, cuti/izin, lembur, dan payroll pegawai pabrik.

> Development aktif dilakukan di branch `development`. Branch `main` dipertahankan sebagai baseline sampai perubahan direview.


## Release
